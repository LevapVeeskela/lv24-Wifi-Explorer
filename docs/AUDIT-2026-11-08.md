## Статус (обновлено 2026-11-08)

Большая часть плана закрыта: P0-фиксы, open-source пакеты, реальные macOS-данные,
расширенные колонки, issues inspector, IE diff, release hardening. Актуальный
состав релиза — `CHANGELOG.md`, ограничения — `docs/PARITY-GAP.md`.

## Вердикт

TS-ядро в рабочем состоянии (`typecheck` ✅, 175 тестов ✅, lint ✅), но релиз 0.1.0 **не готов**:
в собранном приложении не работает preload (sandbox), скан по умолчанию демонстрационный,
Flutter-workbench падает на первом кадре, часть гейтов красная, CSP/CSV/импорт снапшота требуют
ужесточения. Парити с оригиналом близко по базе, следующий слой — колонки из IE, Issues inspector,
IE-diff, правила/профили, Flutter-сортировка/группировка.

## План закрытия (этот цикл)

### R1. Electron: живой скан, preload, security — P0

- `bootDemoModeFromArgv`: live по умолчанию; demo только `--demo` / `WIFI_EXPLORER_DEMO=1`;
  fallback на фикстуры — явный статус, без подмены `source`/`demo` в снапшоте.
- Preload: убрать относительный `require` (sandboxed preload), инлайнить каналы меню.
- `setWindowOpenHandler` allowlist (`https:`, `mailto:`), `will-navigate` guard, проверка
  `event.senderFrame.url` в IPC, `Number.isFinite` + clamp интервала.
- CSP: prod `connect-src 'self'`, dev — только Vite.

### R2. ScanCore Swift: транспорт и lifecycle — P0/P1

- Сериализованный writer, цикл до полной записи, обработка `EPIPE`.
- `shutdown` без `queue.sync`-дедлока; SIGTERM/SIGINT через `DispatchSourceSignal`.
- Остановка helper: `shutdown` → ожидание → `SIGKILL`; `stdin.on('error')`.
- Handshake timeout + проверка `protocolVersion`; бинарь в packaged — только `resourcesPath`.

### R3. Renderer hardening — P0

- Валидация `.lv24scan`: структура каждого BSS, лимиты count/length, отказ `invalid-document`.
- CSV formula injection guard (`= + - @ \t \r`) + BOM для аннотаций.
- Лимит размера импортируемого файла.

### R4. Flutter P0/P1

- `PersistedScanColumns` выше `ScanWorkbenchPage`; убрать `visibilityOf` из `build` страницы.
- Цифры `1–4` — только с модификатором; не перехватывать при фокусе в `EditableText`.
- OUI registry + фикстуры как `assets` (`rootBundle` + файловый fallback).
- `_disposed` guard в сессиях, debounce/onChangeEnd записи настроек, dispose контроллеров.
- Починить `flutter test`/`analyze`: compile error, widget test, android miss expectation.

### R5. Quality gates

- `test:scan` → конкретный файл; scan-тесты вернуть в Vitest-гейт.
- CI под Yarn 1 (`--frozen-lockfile`), шаги typecheck/lint/test/format/build, manual-only.
- `yarn format` до зелёного `format:check`.
- `dist:mac`: `build:scancore` перед сборкой, `minimumSystemVersion: 13.5`,
  universal helper (arm64+x86_64) или честный arm64-only target.

### R6. Парити-пакет desktop

- Колонки из готовых данных: first seen/uptime/seen %, center frequency, max rate, streams,
  amendments/generation, country, beacon interval, DTIM, BSS load, channel utilization,
  IE count/bytes, WPS/MFP/FT.
- Единая формула RSSI→% (domain), исправить `signal:>=50%`.
- Issues inspector + facet + 4 эвристики (2.4-only, separate names, too many, large group);
  устранить O(n²) и self-neighbor.
- IE tree: length, copy element/field/all, expand/collapse all.
- Compare: IE diff, hide identical, present-only.
- Аннотации: pin colors, count, confirm replace, CSV guard.
- Sidebar facets: channel/width/PHY/type/issues/annotations; selected-only.
- Согласовать фильтры с доменом (secure/unknown, vendor OUI, hidden, presence/SNR).

### R7. Flutter parity

- Сортировка, organize-by SSID/AP/vendor, filter presets, CSV по видимым колонкам,
  единый vendor-фолбэк, pin colors в таблице.

### R8. Docs

- `PARITY-GAP.md`, `SPEC.md` (thresholds/issue ids/presence), `ARCHITECTURE.md` (OUI в renderer,
  helper events), `README.md` (Yarn, 13.5, packages), `packages/desktop/src/scan/README.md` (флаги).

## Вне плана (обосновано)

Passive/monitor, spectrum hardware, clients, BLE/Zigbee, remote sensors, `.wifiexplorer`,
vendor logos — платформенно невозможно или clean-room/trademark исключение.
Coloring rule sets + unified profiles import/export + history multi-trace/utilization —
следующий цикл (крупные UI-фичи, не блокируют релиз).

## Критерии приёмки

`yarn typecheck && yarn lint && yarn test && yarn format:check && npx vite build` — зелёные;
`flutter analyze && flutter test` — зелёные; `yarn test:scan` — зелёный; новые тесты на
P0-фиксы; docs синхронизированы; ручной smoke: live-скан при наличии helper, demo badge при
fallback, preload bridge доступен.

## Результат цикла

- R1–R5 закрыты: live по умолчанию, sandbox-preload, security guards, Swift transport/lifecycle,
  валидация `.lv24scan`, CSV guard, quality gates (Yarn CI, `test:scan`, Flutter analyze/test,
  universal ScanCore, format).
- Open-source packaging: `packages/core`, `packages/backend`, `packages/cli`, `packages/web`,
  `packages/desktop`; MIT LICENSE; cross-platform providers macOS/Linux/Windows/demo;
  `lv24-wifi` CLI проверен на demo и live macOS.
- P0 Flutter: provider вокруг workbench, цифры только с модификатором, OUI assets,
  dispose/refresh fixes; `flutter test` 199 pass.
- Parity quick wins, требующие UI-полировки (coloring rule sets, unified profiles,
  history multi-trace, Flutter sort/organize/presets), остаются в Phase 2.
