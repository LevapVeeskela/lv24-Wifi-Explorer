**Краткое описание (до 270 символов):**

```text
Честный сканер Wi-Fi: сигнал, каналы, безопасность и диагностика. Без телеметрии и выдуманных данных.
```

**Полное описание:**

```text
LV24 WiFi Explorer — честный кроссплатформенный сканер Wi-Fi для людей и ИИ-агентов.

Приложение показывает реальную картину эфира: уровень сигнала, загрузку каналов, пересечения сетей, безопасность и типовые проблемы. Данные не выдумываются: если Windows или адаптер не отдают поле, вы увидите «—» или «unknown», а при отсутствии живого скана — явную пометку demo.

Возможности:
• живой скан и история сигнала;
• загрузка каналов и пересечения BSS;
• инспектор проблем: слабый сигнал, перегрузка, открытые сети, DFS, скрытые SSID;
• фильтры, пресеты, сохранённые профили, аннотации и правила раскраски;
• сравнение BSS и diff information elements;
• экспорт CSV, печать, снимки .lv24scan, импорт pcap/pcapng;
• интерфейс на русском, английском и китайском;
• без телеметрии, рекламы и аккаунтов.

На Windows приложение использует встроенный netsh, на Linux — NetworkManager, на macOS — CoreWLAN. Windows/Linux версии честно показывают, какие поля недоступны, вместо того чтобы их угадывать.
```

## English (en-US)

**Short description (up to 270 characters):**

```text
An honest Wi-Fi scanner: signal, channels, security and diagnostics. No telemetry, no invented data.
```

**Full description:**

```text
LV24 WiFi Explorer is an honest cross-platform Wi-Fi scanner for people and AI agents.

It shows what is really in the air: signal strength, channel occupancy, overlapping networks, security and common issues. Missing data is never guessed: when Windows or the adapter does not provide a field, you see "—" or "unknown"; when live scanning is unavailable, the app shows a clearly labelled demo set.

Features:
• live scan and signal history;
• channel occupancy and BSS overlap;
• issues inspector: weak signal, congestion, open networks, DFS, hidden SSIDs;
• filters, presets, saved profiles, annotations and coloring rules;
• BSS compare with information-element diff;
• CSV export, printing, .lv24scan snapshots, pcap/pcapng import;
• English, Russian and Simplified Chinese UI;
• no telemetry, ads or accounts.

On Windows it uses the built-in netsh, on Linux NetworkManager, on macOS CoreWLAN. The Windows and Linux builds show which fields are unavailable instead of inventing them.
```

**Keywords:** `Wi-Fi, Wi-Fi scanner, channel analyzer, network diagnostics, Wi-Fi security, signal`

**What's new (1.0.0):**

```text
First public release: live scan, signal history, channel occupancy, issues inspector, filters, profiles, annotations, BSS compare, CSV export, printing, .lv24scan snapshots and pcap/pcapng import.
```

## 简体中文 (zh-CN)

**简短说明（最多 270 个字符）：**

```text
诚实的 Wi-Fi 扫描器：信号、信道、安全与诊断。无遥测，不编造数据。
```

**完整说明：**

```text
LV24 WiFi Explorer 是一款面向用户和 AI 代理的诚实 Wi-Fi 扫描器。

它展示真实的无线环境：信号强度、信道占用、网络重叠、安全性和常见问题。缺失的数据绝不猜测：当 Windows 或网卡不提供某个字段时，会显示“—”或“unknown”；无法实时扫描时，会显示带有明确标记的演示数据。

功能：
• 实时扫描与信号历史；
• 信道占用与 BSS 重叠；
• 问题检查：弱信号、拥塞、开放网络、DFS、隐藏 SSID；
• 过滤器、预设、保存的配置、注释和着色规则；
• BSS 对比与信息元素差异；
• CSV 导出、打印、.lv24scan 快照、pcap/pcapng 导入；
• 英文、俄文和简体中文界面；
• 无遥测、无广告、无需账户。

Windows 版使用系统自带的 netsh，Linux 版使用 NetworkManager，macOS 版使用 CoreWLAN。Windows 和 Linux 版本会明确显示哪些字段不可用，而不是编造数据。
```

**关键词：** `Wi-Fi, Wi-Fi 扫描器, 信道分析, 网络诊断, Wi-Fi 安全, 信号`
